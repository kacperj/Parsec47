This is a Rust port of PARSEC47, the classic shoot-'em-up originally created by Kenta Cho (ABA Games).

This repo was motivated by a few goals:
1) The D language has a relatively small community.
2) Consolidate on a single language — the original game mixed two (C++ and D).
3) Offer a single build step (Docker) that produces builds for multiple platforms and can itself be run on multiple platforms.
